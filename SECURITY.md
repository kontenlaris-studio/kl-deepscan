# Security Policy

## Reporting a vulnerability in KL-DeepScan

If you find a security issue in KL-DeepScan itself, please report it privately
to **kontenlaris.studio@gmail.com** instead of opening a public issue. Include
what you found, how to reproduce it, and the version/commit you tested. We aim
to acknowledge reports within a few days.

## Scope notes

- KL-DeepScan is a **detection-only** scanner intended for systems you own or
  are authorized to test. Reports about "the scanner detects X" are feature
  requests, not vulnerabilities.
- False positives/negatives in checks are welcome as regular public issues —
  include the target response (redacted) that triggered them.
- Never include real API keys, credentials, or third-party scan results in
  issues or reports.
